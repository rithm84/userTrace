Troubleshooting

  • The agent appears only after the session tab offers a binding and the preview page proves it runs the uTrace SDK.
  • Incognito, guest, file, PDF, browser-internal, and other extension pages are unsupported preview contexts.
  • If page access is missing, the agent cannot appear in any preview tab.
  • Status text for the interview lives in the uTrace session tab, not on the orb.
